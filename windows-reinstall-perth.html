If the drive is failing, a reinstall only lasts until it fails again, so the drive gets replaced first and your files moved across. If the hardware is healthy, we repair Windows in place where we can, which keeps every program and setting, and reinstall it only when repair is not enough. If the drive has already failed and your files matter, the data recovery page explains how they come back.

Windows updates matter, since most of them close security holes. When one fails, Windows usually tries it again at the next restart, fails again, and rolls back, sometimes every day. Meanwhile the computer is missing every fix that came after it.

A stuck update is often caused by a damaged update store, not enough free space, a driver that is out of date, or a drive that is starting to fail. We find which one, clear it, and get the computer fully up to date, so later updates install normally. If an update broke something that used to work, we fix that too.

- id: windows-11-ready group: "Windows 11 upgrade" title: "Is my computer ready for Windows 11?" price_key: windows-11-upgrade text: |

Windows 11 needs a reasonably recent processor, a security chip called TPM 2.0, Secure Boot, at least 4GB of memory and 64GB of storage. Most computers bought from around 2018 onwards meet these. Many that fail the check only need a setting switched on in the computer's firmware, which we do as part of the upgrade.

Some older computers genuinely cannot meet them. Windows 11 can sometimes be forced onto them, but Microsoft does not promise updates for those machines, and we will not sell you an upgrade that leaves you worse off. If yours is one of them, we tell you plainly and talk through the options, including whether a new drive and memory make the machine worth keeping, or whether it is time to move your files to a new one. sections: - id: repair-or-reinstall title: "Repair Windows or reinstall it?" html: |

Repair first, when repair will hold. It keeps every program and setting, and many problems, such as a stuck update or a damaged system file, can be fixed without a fresh start.

A reinstall is the better choice when the problems keep coming back after repair, when the computer is years deep in leftover programs and settings, when it has been badly infected, or when it is being handed to someone else. It is also the most reliable way to make an older computer feel new again, alongside an SSD if it still has a mechanical hard drive.

Either way, the hardware is checked first. A reinstall cannot fix a failing drive, faulty memory or overheating, and we would rather tell you that up front than charge for a fix that will not last. The slow computer page covers those hardware causes in detail.

  • We check the drive, memory and temperatures, so Windows goes onto healthy hardware.

- id: windows-10 title: "Windows 10 end of support: what it means for you" html: |

A computer on Windows 10 keeps working. What stops is the monthly security fixes. Every new weakness found from now on stays open on that computer, and that matters most on a computer used for banking, email and shopping.

Microsoft offered home users a year of extra security updates through its Extended Security Updates programme, running until October 2026. That buys time, not a fix. For most computers the real answer is Windows 11, and for a computer that cannot take it, an honest conversation about whether it is worth keeping.

Moving to Windows 11 is also a good moment for a clean start. If the computer has been slow or unreliable on Windows 10, a fresh install of Windows 11 rather than an upgrade over the top often fixes both at once.
