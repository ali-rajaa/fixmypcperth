Most programs install a small helper that launches every time Windows does: update checkers, cloud sync, chat apps, printer tools, game launchers. None of them ask first. Each one takes a share of memory and processor time before you have opened anything yourself, and after a few years of installs a machine can be carrying dozens of them.

On its own this is the mildest cause on the list. It does not damage anything and it does not get much worse from week to week. The catch is that it often sits alongside one of the more serious causes below, and a machine that has been tidied up but still has a worn-out drive will only feel slightly better.

- id: memory title: "Not enough memory for how you use it now" urgency: can-wait urgency_label: "Can wait" price_key: ram-upgrade-supplied text: |

Memory, or RAM, is the short-term workspace a computer uses for whatever is open right now. Web browsers, Windows itself and everyday apps all ask for more of it than they did a few years ago, so a machine that had plenty when it was bought can be short today without anything having gone wrong.

When that workspace fills up, Windows moves data out to the storage drive to make room, and storage is far slower than memory. Everything drags while that happens. It does not harm the machine, but it is a hardware limit: no amount of cleaning adds memory that is not there.

- id: old-drive title: "An old mechanical hard drive" urgency: book-this-week urgency_label: "Book this week" price_key: hdd-to-ssd-full-migration text: |

This is the cause we see more than any other. A mechanical hard drive stores data on a spinning disk and reads it with an arm that physically moves into place. A solid-state drive, or SSD, has no moving parts at all. Windows reads thousands of small files just to start up and open a program, and a mechanical drive handles that kind of work very slowly.

Plenty of computers sold only a few years ago still shipped with one. The rest of the machine can be perfectly capable and still feel slow at almost everything, because every task waits on the drive first. Mechanical drives also wear out. An older one is the likeliest reason for the slowness and the part most likely to fail next, which is why we would not leave it for months. Our SSD upgrade guide covers how much faster the same machine gets once the drive is replaced.

- id: heat title: "Heat and dust" urgency: book-this-week urgency_label: "Book this week" price_key: overheating-fix-deep-clean text: |

Processors are built to protect themselves. When they run too hot they deliberately slow down, which is called thermal throttling. Dust is the usual reason they run hot. It collects on the cooling fins and fans over years of normal use, and the thermal paste between the processor and its cooler dries out with age.

Throttling is the machine doing its job, but it is also a warning. Heat bad enough to slow the processor is shortening the life of the parts around it, and on a laptop it can end with the machine switching itself off mid-task. It only gets worse as more dust builds up.

- id: malware title: "Malware running in the background" urgency: book-this-week urgency_label: "Book this week" price_key: virus-malware-removal text: |

Not every infection announces itself with pop-ups. A lot of modern malware is built to stay quiet, because a program nobody notices can keep running for months. It uses the processor and the internet connection for its own purposes, and the only thing the owner notices is a computer that feels slower than it should.

The slowdown is the least of the problem. Software running without your knowledge may also be reading what you type or what is stored on the machine, including saved passwords and banking logins. That is why this one should not wait for a convenient month. Our guide to virus warning signs covers what an infection can do beyond slowing things down.

- id: failing-drive title: "A drive that is failing" urgency: stop-now urgency_label: "Stop using it now" price_key: data-recovery-failing-drive text: |

This is not the same as an old drive that is simply slow. A failing drive is breaking down. Parts of it can no longer be read reliably, so it retries the same spot again and again before giving up. From the outside that looks like an ordinary slow computer, which is exactly why it gets mistaken for one.

The difference matters more than anything else on this page. Every hour a failing drive keeps running can damage files that are still recoverable today, and attempts to clean it up, speed it up or reinstall Windows on it make that worse. If a slow machine holds anything you cannot replace, have the drive checked before anything else is done to it. Our guide to failing hard drives explains why the timing matters so much.

- id: clutter title: "Years of built-up clutter in Windows" urgency: can-wait urgency_label: "Can wait" price_key: windows-reinstall-data-backup text: |

A Windows installation that has lived through years of updates, driver changes and programs installed and half removed carries a lot of leftover weight. None of it is one big fault. It is the slow build-up of a system that has never had a fresh start.

It is rarely urgent, and it is the cause most often blamed for problems that are really one of the hardware causes above. A fresh install on a worn-out drive is still slow. Once the hardware is known to be sound, though, a clean reinstall with your files carried across can make an older machine feel far better than people expect. When a fresh start is the answer, the Windows reinstall page explains what is involved.
